# OpenClaw只能装在Mac mini？你离手机养🦞只差这篇小白级手把手攻略

打开任何一个 OpenClaw 教程，你都会看到这句话：「你需要一台 Mac Mini 作为 host 机，24 小时开着。」

然后呢？- 没有 Mac Mini？去买一台，几千块。没地方放？腾出桌面空间......
很多人看到这里就关掉了页面。

但仔细想想，OpenClaw 本身是一个开源的 AI Agent 框架，它需要的是一个「计算环境」。为什么非要 Mac Mini？

直到发现了 BotDrop。它把 OpenClaw 跑在安卓手机上。正好家里有台闲置的 Pixel 9，装上 BotDrop，连上 Telegram，几分钟就有了一个 24 小时在线的 AI 助手。

不需要 Mac Mini，不需要云服务器，一台吃灰的安卓机就够了。

所以当我发现 BotDrop （[https://botdrop.app/](https://botdrop.app/)）把 OpenClaw 跑在安卓手机上时，第一反应不是「卧槽这是什么」，而是：

「为什么没人早点告诉我？」

技术门槛，就是现代社会的种姓制度。

这一次就是为了打破这一次的技术门槛！

![image-01.jpg](/images/blog/x-2032079304427966602/image-01.jpg)

两句话说完。首先感谢大佬 [@zhixianio](https://x.com/@zhixianio) 制作的软件才能如此轻松！

BotDrop 是一个安卓 App，让你在手机上一键安装并运行 AI Agents。

- 不需要服务器，不需要命令行终端

- 连 Telegram、Discord、飞书等平台，直接在这些 App 里和 AI 对话

- 支持 Claude、GPT、Gemini、DeepSeek、还能自定义提供商，这就给在国内使用第三方中转API的小伙伴提供了很大的便利！

- 最新版本 V0.2.8 可以直接看手机屏幕、自动点击、滑动、打字

装完之后，你的手机就是一个24小时在线的AI节点。

24 小时在线，你不在的时候它在。

目前BotDrop已经迭代非常多代，下载后按照要求操作即可，非常简单！

![image-02.jpg](/images/blog/x-2032079304427966602/image-02.jpg)

点击OpenClaw 旁边的“安装” 。BotDrop 会自动设置环境、验证 Node.js 并安装 OpenClaw。差不多需要 3-5 分钟。

![image-03.jpg](/images/blog/x-2032079304427966602/image-03.jpg)

第二步是选择你的AI Model，包括MiniMax啊KIMI啊Deepseek都是没有问题的

![image-04.jpg](/images/blog/x-2032079304427966602/image-04.jpg)

第三就是选择你的聊天平台了，我当时只支持Telegram和Discord，现在飞书也可以了！当然，三个一起连接也没有问题。

![image-05.jpg](/images/blog/x-2032079304427966602/image-05.jpg)

根据不同社交媒体需要的内容去输入token跟user id就可以了，点击CONNECT & START。

![image-06.jpg](/images/blog/x-2032079304427966602/image-06.jpg)

如果一切顺利，那么连接完成后，仪表盘会显示网关的状态。

如果显示 Gateway running 也就是绿色灯亮起，那就表示正在运行中，仪表盘是我目前为止认为对小白最友好的一个页面之一了，既能够看到Openclaw的日志，也可以直接点击它的Web UI，还可以检查有没有需要更新，包括模型切换也非常方便，

然后这个启动、暂停跟重启的按键也非常清晰，最底部呢，其实还有一个Terminal，但是对我们大部分人来说，其实不用Care。

![image-07.jpg](/images/blog/x-2032079304427966602/image-07.jpg)

官方给出了文档，非常详细，可以参考这部分去配置：[https://docs.botdrop.app/zh/channels/feishu/](https://docs.botdrop.app/zh/channels/feishu/)

不过飞书部分特别提醒，必须在「事件配置」里面添加「接收消息」

![image-08.jpg](/images/blog/x-2032079304427966602/image-08.jpg)

然后去聊天窗口说两句，获得id，回到botdrop填进去并且再次连接

![image-09.jpg](/images/blog/x-2032079304427966602/image-09.jpg)

装完 BotDrop 后，我试着跟它说：「你能帮我去刷小红书吗」

它回我：「这个设备上没有浏览器，刷不了」

等等！小红书就装在这台手机上。打开就能看到。为什么要浏览器？

因为 OpenClaw 根本不知道手机上有这个软件。

它被关在 Android 的沙盒里，说人话就是每个 App 只能看到自己的数据，碰不到外面的世界。

这就像雇了个全能助理，把他锁在一个没有窗户的房间里，然后让他帮你看隔壁房间的东西。

他只能说：「给我钥匙吧。」

但明明钥匙就在这栋楼里。它只是出不去拿。

接下来的故事，就是帮它开门的过程。

![image-10.jpg](/images/blog/x-2032079304427966602/image-10.jpg)

在开始前，大家一定要先确保手机进入「开发者模式」，并且允许调试，当然如果遇到问题，不要紧，我们还有秘密武器：Claude Code

我平时用 Claude Code 写代码，所以我这一次直接要求 Claude Code：我现在要求你进入我的手机帮我部署好OpenClaw，权限已经打开，剩下的交给你了！

BotDrop 自带 SSH 功能，在设置里打开，你会看到 IP 地址、端口号、用户名、密码，这些CC它会去帮你操作。

到现在为止，你做的事只是安排CC工作。不过请注意，这个过程里面会要求你重置手机，虽然我已经要求不允许CC执行该操作，我已经确保手机里面没有隐私信息。这也就是为什么我要求各位必须闲置手机，或者你买个全新的来玩（不推荐）都行。

遇到问题，不要试图自己解决，请让AI去解决。

和AI沟通的时候，你只需要说你的目标。

「我想让手机上的小红书能帮我刷小红书、操作手机上的任何 App。你现在已经连上手机了，帮我想办法。」

就这一句话。

AI 会自己去调查你的手机是什么型号、什么芯片，为什么 OpenClaw 没有权限，怎么突破限制，这个型号具体怎么操作，需要什么工具、从哪下载

然后它开始执行。

<video controls preload="metadata" poster="/images/blog/x-2032079304427966602/video-01-poster.jpg" src="/images/blog/x-2032079304427966602/video-01.mp4" aria-label="嵌入式视频"></video>

整个过程，我只干了这几件事：

- AI 让我在手机上装一个 App → 装

- AI 让我在手机上点某个按钮 → 点

- AI 让我把手机用 USB 插到电脑 → 插

- AI 让我长按某个组合键重启手机 → 按

每一步 AI 都会明确告诉你做什么。你不需要理解为什么。

一定会遇到问题。我遇到了：

- 找不到固件 → AI 找了个同芯片的「姊妹机型」解决

- 刷入失败 → 换了根数据线（第三方线不兼容）

- 权限还是不通 → AI 设计了个小服务，让里面的 OpenClaw 借外面的权限

每次卡住，你做的事都一样：把错误信息复制给 AI，让它想办法。

记住：错误不是终点，是 AI 学习的起点。

![image-11.jpg](/images/blog/x-2032079304427966602/image-11.jpg)

手机上的openclaw接管我的Gmail发布邮件

一台 root 过的安卓手机，跑着一个有 root 权限的 OpenClaw。

它可以：

- 截屏看当前界面，分析 UI 元素，模拟点击和输入

- 凌晨 3 点帮你抢票、秒杀

- 工作群半夜炸了帮你判断要不要叫醒你

- 操作小红书、外卖、打车这些纯移动端 App

24 小时在线，你不在的时候它在帮你干活。

Q: OpenClaw 过几个小时就断了

A: Android 的省电机制会杀后台。跟 AI 说「帮我查这个手机怎么关省电优化」。

Q: 手机重启后还能用吗

A: 能。所有设置都是持久的。

Q: BotDrop 更新后图片又不行了

A: 跟 AI 说一声，重新修一遍就好。

Q: 我的手机能用吗

A: 大部分一加、小米、Pixel 都行。华为近几年的不行。不确定的话，告诉 AI 你的手机型号，让它帮你判断。

Q: 没有 Mac 能做吗

A: 能。Mac / Linux / Windows 都行。

总耗时大约 2 小时，全程没写一行代码。

你抽屉里的那台旧手机，不是垃圾，是还没被发现的 AI 节点。

不需要 Mac Mini 24 小时开着，不需要云服务器按小时计费。一台吃灰的旧手机，就是一个永远在线的 AI 节点。
